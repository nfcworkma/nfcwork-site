# Kiffy — maquettes de référence

Source : canvas Claude « Kiffy — logo et plaque » (https://claude.ai/artifact/5Jm6ohqPrCip2vxCzAShGw).
Chaque `*.dc.html` est un écran (390 × 844, sauf mention). Le HTML est à reproduire fidèlement
(couleurs, espacements, textes). Les `/_blob/...` sont des images du canvas : utiliser à la place
`assets/wallet/fond-<métier>.png`, `assets/wallet/apple-wallet-icon.png`, `assets/wallet/badge-google-fr.svg`.

Charte : vert #16C172, noir #0A0A0A (toute l'écriture), fond #F4F7F5, blanc.
Logo « kiffy » : Bricolage Grotesque 800. Texte : Inter.
Slogan : « Approchez. Cumulez. Gagnez. »
